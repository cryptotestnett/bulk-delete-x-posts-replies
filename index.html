Frequently Asked Questions

Which tab on X should I open for Posts, Replies, and Reposts?
  • Replies: open x.com/USERNAME/with_replies.
  • Posts: open your main profile page, x.com/USERNAME.
  • Reposts: also open your main profile page, x.com/USERNAME, since your reposts appear there alongside your posts.

Make sure the tab matches the script you selected above before you paste it into the Console.

Is this safe for my account?
The scripts run entirely inside your own browser tab on the X website you're already logged into. They don't ask for your password or API keys, and nothing is sent to a third-party server. Deletions are permanent, though, so double-check which mode you've selected. As with any code you paste into a console, read it first — it's open source and fully readable.
Why did it stop before deleting everything?
X loads your timeline lazily, so older items only appear after the page scrolls to them. If the script finishes while items remain, the page may have run out of loaded content, the tab may have been hidden or in the background, or X may have briefly slowed down. Keep the tab visible, refresh with F5, and run the script again once. Repeat until the console logs FINISHED! with nothing left.
How do I stop the script early?
Refresh the page with F5. That clears the running script from memory, so nothing continues in the background. Anything already deleted stays deleted.
